## 待编写章节结构（已讨论确认）

1. **命名规范（TS/React 专属）**：变量/函数 camelCase、React 组件 PascalCase、Hook 用 `use` 前缀、常量 UPPER_SNAKE_CASE、CSS 类名（待组件库定后补充）
2. **代码风格**：**Prettier + ESLint 强制**、缩进 2 空格（JS 社区主流）、单引号、分号规则、import 排序
3. **错误处理**：消费后端错误码 + 转用户友好提示、try/catch 范围精确、全局错误边界（React Error Boundary）、网络错误重试/降级策略
4. **日志规范**：console 级别规范（开发期用，生产移除或转上报）、错误上报机制、**密钥绝不进前端代码**
5. **编码实践**：React 组件设计（函数组件/Hook 优先，不用 class 组件）、TypeScript 类型规范（禁 any/接口优先/类型推导）、状态管理方案（待定：Context/Zustand/其他）、Hook 使用规范（依赖数组/自定义 Hook 抽取）
6. **依赖管理**：npm/package.json、lock 文件必须提交、依赖锁定、何时该加依赖
7. **配置项管理**：.env 文件、Vite 环境变量（`VITE_` 前缀）、不同环境配置（dev/build）
8. **安全编码（前端专属）**：防 XSS（React 默认转义，禁 dangerouslySetInnerHTML 滥用）、防 CSRF、敏感信息绝不进前端代码、用户输入处理
9. **组件/API 设计**：Props 设计（最小化/可组合/明确类型）、组件拆分原则（单一职责/可复用）、目录组织（components/hooks/pages/services/types）
10. **性能编码**：避免不必要的 re-render（memo/useMemo/useCallback）、组件懒加载（React.lazy）、打包体积控制、长列表虚拟化
11. **测试规范（前端专属）**：Vitest + Testing Library、组件测试/Hook 测试、mock API、覆盖率要求
