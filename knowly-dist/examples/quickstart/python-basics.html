Python 基础入门

Python 是一种广泛使用的高级编程语言，由 Guido van Rossum 于 1989 年发明。Python 强调代码可读性，语法简洁，适合初学者入门。

一、变量与数据类型

Python 是动态类型语言，变量无需声明类型。常见数据类型包括：整数（int）、浮点数（float）、字符串（str）、布尔值（bool）、列表（list）、字典（dict）。

二、控制流

Python 的控制流包括条件判断（if/elif/else）和循环（for/while）。与多数语言用花括号不同，Python 使用缩进来表示代码块，这是 Python 最显著的语法特征。

三、函数

用 def 关键字定义函数。函数可以接受参数、返回值，也支持默认参数、关键字参数、可变参数等灵活的调用方式。Python 还支持 lambda 匿名函数，适合编写简单的单行函数。
