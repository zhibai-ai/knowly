## 1. 依赖清单

### 1.1 必装

| 依赖 | 版本 | 用途 | 安装方式（Ubuntu） |
|---|---|---|---|
| JDK | 17+ | Java 运行时 | `apt install openjdk-17-jdk` |
| Maven | 3.8+ | 构建 | `apt install maven` |
| Git | 任意 | 克隆代码 | `apt install git` |

### 1.2 按需安装

| 依赖 | 版本 | 用途 | 安装方式 |
|---|---|---|---|
| Tesseract OCR | 5.x | 扫描版 PDF / 图片 OCR | `apt install tesseract-ocr tesseract-ocr-chi-sim` |
| 中文字体 | — | PDF 渲染中文 | `apt install fonts-noto-cjk` |
| PostgreSQL | 15+ | PgVector 向量库（可选） | `apt install postgresql` |
| PgVector 扩展 | — | 向量类型支持 | `apt install postgresql-15-pgvector` |
| Qdrant | — | 向量库（可选） | `docker run -p 6333:6333 qdrant/qdrant` |
| Node.js | 18+ | 前端构建 | `apt install nodejs npm` |
| DashScope API Key | — | embedding 向量化 | [申请地址](https://dashscope.aliyun.com/) |

## 2. 构建打包

### 2.1 克隆代码

```bash
git clone https://github.com/zhibai-ai/knowly.git
cd knowly
```

### 2.2 构建后端

```bash
cd knowly-server
mvn clean install -DskipTests
```

产出：
- `knowly-cli/target/knowly-cli-0.1.0-SNAPSHOT.jar`（CLI 可执行 fat jar）
- `knowly-api/target/knowly-api-0.1.0-SNAPSHOT.jar`（Web API Spring Boot jar）

### 2.3 构建前端

```bash
cd knowly-web
npm install
npm run build
```

产出：`knowly-web/dist/`（静态资源，可由 nginx 托管）

## 3. 启动

### 3.1 CLI 模式

```bash
# 生成配置
java -jar knowly-server/knowly-cli/target/knowly-cli-0.1.0-SNAPSHOT.jar init

# 运行清洗
java -jar knowly-server/knowly-cli/target/knowly-cli-0.1.0-SNAPSHOT.jar run \
  --config pipeline.yaml \
  --input ./docs \
  --output ./output
```

### 3.2 Web 模式

```bash
# 启动后端 API（端口 8080，仅监听 127.0.0.1）
java -Xmx512m -jar knowly-server/knowly-api/target/knowly-api-0.1.0-SNAPSHOT.jar

# 启动前端（开发模式，端口 5173）
cd knowly-web
npm run dev
```

访问 http://localhost:5173，默认账号 `admin / admin123`

### 3.3 环境变量

| 变量名 | 用途 | 默认值 |
|---|---|---|
| `DASHSCOPE_API_KEY` | DashScope embedding API Key | 无（需要向量化时必填） |
| `KNOWLY_HOME` | 知了工作目录（存配置/状态/产出） | `/data/knowly` |
| `TESSDATA_PREFIX` | Tesseract 语言包路径 | 自动检测 |
| `PG_PASSWORD` | PgVector 连接密码（在模板中使用） | `knowly_dev` |

## 4. Docker 部署（计划中）

> v0.1 暂未提供 Docker 镜像，v0.2 补充 Dockerfile + docker-compose。

规划：
```yaml
# docker-compose.yml（计划）
services:
  knowly-api:
    image: knowly/api:latest
    ports: ["8080:8080"]
    environment:
      - DASHSCOPE_API_KEY=${DASHSCOPE_API_KEY}
    
  knowly-web:
    image: knowly/web:latest
    ports: ["80:80"]
    
  postgres:
    image: pgvector/pgvector:pg16
    ports: ["5433:5432"]
    
  qdrant:
    image: qdrant/qdrant
    ports: ["6333:6333"]
```

## 5. 健康检查

Web 模式启动后，检查后端是否正常：

```bash
curl http://localhost:8080/api/auth/login \
  -X POST \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123"}'
```

返回 `{"code":0,"data":{"token":"..."}}` 表示正常。

## 6. 常见问题

| 问题 | 原因 | 解决 |
|---|---|---|
| `mvn install` 下载慢 | 默认 Maven 中央仓库国内慢 | 配置阿里云镜像（`~/.m2/settings.xml`） |
| OCR 报错找不到 Tesseract | Tesseract 不在 PATH | `apt install tesseract-ocr tesseract-ocr-chi-sim` |
| 中文渲染乱码 | 缺中文字体 | `apt install fonts-noto-cjk` |
| PgVector 报 extension 不存在 | PgVector 扩展未装 | `apt install postgresql-15-pgvector` |
| embedding 报 401 | API Key 未配 | 设置环境变量 `DASHSCOPE_API_KEY` 或通过 Web 设置页配置 |
| Web 页面打不开 | 前端未启动 | `cd knowly-web && npm run dev` |
| 文件选择失败 | 后端未启动 | 检查 `localhost:8080` 是否在监听 |
