## 待编写章节结构（已讨论确认）

1. **命名规范（Java 专属）**：包名 `com.knowly.{module}`、类名 UpperCamelCase、接口不加 I 前缀、SPI 实现用 `{技术}{角色}`（如 `PgVectorSink`）、`Impl` 后缀
2. **代码风格**：4 空格、行宽 120、K&R 花括号、import 不通配、**spotless + checkstyle 强制**
3. **异常处理与错误码**：`KnowlyException`（RuntimeException）体系 + 子类、一律非受检、异常含上下文、**错误码 v0.1 就做**（`{阶段}_{序号}` 如 `PARSE_001`）
4. **日志规范**：结构化 JSON、级别使用（ERROR/WARN/INFO/DEBUG）、`{}` 占位符、密钥强制脱敏、必含 traceId/documentId/stage
5. **编码实践**：设计模式使用规范（工厂+注册表/观察者/责任链/适配器/模板方法/策略，不过度）、枚举规范（单数名/UPPER_SNAKE/带描述字段）、常量与静态变量（集中管理/魔法数字提取）
6. **依赖管理**：父 POM 统一版本、BOM、scope 规范（provided/test）、依赖冲突排查
7. **配置项管理**：配置键命名、默认值位置、必填校验、环境变量命名（`KNOWLY_XXX`）
8. **安全编码（后端专属）**：SQL 必须 PreparedStatement 参数化、路径穿越防护（PathSanitizer）、反序列化白名单、YAML SafeConstructor
9. **并发编码**：用 j.u.c（ExecutorService/CompletableFuture）禁裸 Thread、共享状态保护、锁的使用、线程安全集合选择
10. **API/SPI 设计规范**：参数对象化、返回 Optional/不可变集合、异常契约、版本兼容（加字段不破坏老消费方）
11. **性能编码**：循环内不创建对象、字符串拼接用 StringBuilder、流式读取大文件、避免全量加载
12. **测试规范（后端专属）**：JUnit 5 + AssertJ、覆盖率（核心 ≥80%/工具类 100%）、Testcontainers（PostgreSQL）、mock embedding
